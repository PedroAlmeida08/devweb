# Processo para Configuração e Implementação

1. **Instalar MySQL e criar um banco de dados.**

2. **Criar tabelas com um script SQL** em `package script -> tabelas.sql`.

3. **Configurar o banco de dados** em `META-INF -> persistence.xml`.

4. **No Maven**, recarregar todos os projetos para gerar a pasta necessária.

5. **Adicionar o package Console** em `C:\Users\[usuário]\.m2\repository\corejava\console\1.0`.

6. **Build Project** para construir o projeto.

---

# DAO (Data Access Object)

O padrão DAO é utilizado para separar a lógica de acesso a dados da lógica de negócios.

## Exemplo:
- `ProdutoDAO` é a interface.
- `JPAProdutoDAO` é a implementação da interface utilizando JPA.
- O método `GetDAO` retorna um objeto que implementa a interface, como o `JPAProdutoDAO`.

---

# Mapeamento de Entidades com JPA

- `@Entity` é a anotação que mapeia uma classe de domínio para uma tabela.
- `@Table(name="produto")` define o nome da tabela no banco de dados.
- `@Id` é a anotação que define o identificador (ID) da entidade.

### Diferença entre `Long` e `long`
- `Long` (classe) pode ser `null`.
- `long` (tipo primitivo) não pode ser `null`.

---

# Método Transiente

A anotação `@Transient` pode ser usada em métodos ou campos para indicar que eles **não devem ser persistidos** no banco de dados.

---

# Programação do Método `inclui`

A implementação do método `inclui` na classe `JPAProdutoDAO` vai persistir o objeto `Produto`. Isso ocorre **em tempo de execução**, enquanto o método é definido na interface `ProdutoDAO` em **tempo de compilação**.

---

# Dependência Reflection

A dependência `reflections` pode ser usada para facilitar a criação de DAOs dinâmicos, afetando a fábrica de DAOs.

# Data Access Object (DAO) - Padrão de Projeto

- **DAO:** 
    - `ProdutoDAO` é a interface.
    - `JPAProdutoDAO` é a classe que implementa `ProdutoDAO` utilizando JPA.
  
- **Método GetDAO:** Recebe e retorna um objeto de uma classe que implementa aquela interface (retorna `JPAProdutoDAO`).

---

# Detalhes Adicionais sobre o DAO

- `ProdutoDAO.class` aponta para a interface do produto DAO em memória.
- Produto com `id = null` significa que o produto ainda não foi cadastrado no banco de dados, ou seja, é um **objeto transiente**.
- **Em tempo de execução**, o método `inclui` é de `JPAProdutoDAO`.
- **Em tempo de compilação**, o método `inclui` é de `ProdutoDAO`.
